# Звіт про РГР

- `report.md` — джерело звіту (Markdown). Додатки А (модель загроз) і Б (тріаж) включаються
  з `docs/` під час збирання, тому не дублюються.
- `report.pdf` — зібраний звіт (ДСТУ 3008:2015: A4, поля 25/10/20/20 мм, Times New Roman 14,
  інтервал 1,5, нумерація сторінок, підписи рисунків і таблиць у межах розділу).
- `figures/` — рисунки: діаграми (Mermaid → PNG), знімки екрана стендів «до/після», графік до/після.
- `tools/build_report.py` — збирач: `report.md` → HTML → PDF (headless Chrome).
- `tools/make_figures.py` — генератор рисунків (потрібні підняті стенди 8081 «після» і 8082 «до»).

## Збірка

```
python report/tools/make_figures.py   # за потреби перегенерувати рисунки
python report/tools/build_report.py    # report.md → report/report.pdf
```

Застереження про використання генеративного ШІ наведено в кінці звіту (вимога підрозділу 1.3 практикуму).
