# РГР — Аудит захищеності DVWA (варіант 8)

Розрахунково-графічна робота з дисципліни «Безпека програмного забезпечення».
Профіль варіанта 8: **завантаження файлів і обхід каталогів** у застосунку DVWA (PHP).

Готовий звіт: [`report/report.pdf`](report/report.pdf).

## Склад

| Шлях | Зміст |
|---|---|
| `dvwa/` | код DVWA (upstream `502ac15`, перший коміт — без змін) + виправлення РГР |
| `docker-compose.yml`, `docker/` | ізольований стенд: dvwa+db у мережі `internal: true`, проксі на `127.0.0.1` |
| `docs/threat-model/` | модель загроз (DFD, STRIDE, CVSS 3.1, реєстр ризиків, дерево атак) |
| `docs/triage/` | тріаж знахідок автоматизованого аналізу (TP/FP з обґрунтуванням) |
| `tools/` | правила Semgrep, прогін сканерів, калькулятор CVSS, quality gate, перевірка захисту |
| `exploits/` | PoC-сценарії підтвердження вразливостей V1–V9 |
| `tests/regression/` | pytest: кожен PoC має бути заблокований + функціональні тести |
| `tests/unit/` | PHPUnit: модульні тести `SafePath`, `SafeUpload` |
| `scans/` | звіти сканерів «до» і «після», SBOM, порівняння |
| `evidence/` | докази ізоляції, експлуатації, проходження тестів, кодів gate |
| `.github/workflows/` | конвеєр CI: SAST + quality gate, SCA/SBOM, секрети, тести |
| `report/` | звіт (Markdown → PDF) і рисунки |

Стани: тег `rgr-before` — до виправлень (усі PoC відтворюються), `rgr-after` — після.
`git diff rgr-before rgr-after -- dvwa/` показує лише виправлення РГР.

## Швидкий старт

```bash
cp .env.example .env
docker compose up -d --build           # стенд на http://127.0.0.1:8080 (змініть DVWA_PORT за потреби)
python -m venv .venv && . .venv/bin/activate && pip install -r requirements-dev.txt
python -m exploits.poc --evidence evidence/stage3   # відтворення вразливостей
python -m pytest                                    # регресія + функціональні тести
tools/run_scans.sh before                           # прогін сканерів
```

> ⚠️ `dvwa/` — навмисно вразливе ПЗ. Запускати лише в ізольованому стенді на `127.0.0.1`.
> Застосування технік до сторонніх систем заборонено (ст. 361–363-1 КК України).

## УВАГА (вразливості V8, V9)

Під час аудиту у службових сторінках `view_source.php` і `view_help.php` актуальної версії DVWA
виявлено обхід каталогів (розкриття конфігурації та `eval()` довільного файлу), присутній на всіх
рівнях безпеки. Про це слід повідомити викладача, а не оприлюднювати (підрозділ 1.2 практикуму).
